

# AI 相亲交友小程序 - 40页完整版原型文档（视觉+交互全细节）
## 适用：AI生成｜UI设计｜前端开发｜Axure高保真
## 规范：375px 标准宽度
## 底部Tab：首页｜圈子｜动态｜我的

---

# 一、全局 TabBar 规范（所有页面遵循）
- 显示页面：首页、圈子、动态、我的
- 隐藏页面：所有子页面、流程页、弹窗页
- 高度：50px
- 背景：#FFFFFF
- 顶部分割线：1px #F5F5F5
- 图标：24px，未选中#999（线性）、选中#FF6B8B（填充）
- 文字：12px，未选中#999，选中#FF6B8B
- 顺序：首页 → 圈子 → 动态 → 我的

---

# 二、全局视觉规范
- 主色：#FF6B8B
- 背景：#FAFAFA
- 卡片：圆角12px，阴影0 2px 8px rgba(0,0,0,0.06)
- 按钮：主按钮#FF6B8B白字，次按钮白底灰字
- 头像：圆形
- 输入框：圆角8px
- 弹窗：居中、圆角12px
- 短视频：9:16、静音自动播放、点击有声、10秒限制

---

# 三、40个页面完整版（视觉 + 交互 + 状态）

## 页面1：微信授权登录
**视觉**
- 背景：#FFFFFF
- 顶部：LOGO 80px + 标语“遇见对的人”
- 中部：按钮“微信一键登录” 宽280 高44 圆角8 主色
- 底部：勾选框“我已阅读并同意” + 协议文字链接

**交互**
- 未勾选 → 按钮禁用
- 勾选 → 按钮可点
- 点击 → 微信授权
- 成功 → 跳手机号绑定
- 失败 → Toast：授权失败

---

## 页面2：手机号绑定
**视觉**
- 顶部：返回箭头 + 标题“绑定手机号”
- 输入框：手机号
- 输入框：验证码
- 按钮：获取验证码（60秒倒计时）
- 按钮：下一步

**交互**
- 手机号格式错误 → 红色提示
- 验证码错误 → 红色提示
- 验证通过 → 跳实名

---

## 页面3：实名认证
**视觉**

**交互**

## 页面4：人脸核验
**视觉**
- 步骤条 2/3

- 按钮：重新拍摄
- 底部：失败3次 → 显示“人工审核”

**交互**

- 失败3次 → 锁定24小时 + 人工入口
